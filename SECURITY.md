# Sicurezza

## Versioni supportate

Viene supportato soltanto il codice presente sul branch `main`.

## Segnalare una vulnerabilità

Non aprire issue pubbliche con dettagli sfruttabili, credenziali, token o dati personali. Usa la funzione privata **Report a vulnerability** nella scheda Security del repository GitHub. Se non è disponibile, contatta privatamente un maintainer dell'organizzazione `OnionRings-dev` e chiedi un canale riservato prima di condividere i dettagli.

Includi, quando possibile, impatto, passaggi minimi per riprodurre, versione o commit interessato e una proposta di mitigazione. Non eseguire test distruttivi contro l'ambiente di produzione.

In caso di segreto esposto, revocalo nel provider originale e sostituiscilo in
Dokploy se configurato lì; rimuoverlo dall'ultimo commit non è sufficiente.
